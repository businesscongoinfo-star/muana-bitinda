# All Service Immo — Site Web

Site vitrine complet pour un service **Immobilier + Architecture + Construction** en Afrique centrale.

## Contenu
- `index.html` — Site complet en un seul fichier (HTML + CSS + JS, aucune installation requise)
  - Hero + recherche de biens (ville / type / budget)
  - 3 services : Immobilier, Architecture, Construction
  - Catalogue de biens (vente / location) avec filtres
  - Réalisations avec filtres (villas, immeubles, bureaux, rénovation)
  - Processus en 5 étapes
  - Simulateur de devis construction (surface × prix m² × ville × finition)
  - Témoignages, FAQ accordéon
  - Formulaire de contact → redirection WhatsApp
  - Bouton WhatsApp flottant, téléphone, email

## Personnalisation rapide
Dans `index.html`, remplacez :
- `+242060000000` par votre numéro WhatsApp / téléphone réel (3 occurrences + formulaire)
- `contact@allserviceimmo.com` par votre email réel
- Les prix et biens dans le tableau `BIENS` (en bas du fichier, section `<script>`)
- Les projets dans le tableau `PROJETS`
